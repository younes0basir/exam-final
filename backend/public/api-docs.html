🎓 UPF University API

University Management System - RESTful API Documentation

Base URL

http://localhost:8000/api

🔐 Authentication

All API endpoints (except login) require Bearer token authentication. Include the token in the Authorization header:

Authorization: Bearer YOUR_TOKEN_HERE
POST /api/login

Authenticate and receive an access token

Request Body:

{ "email": "admin@upf.ma", "password": "password" }

Response (200 OK):

{ "user": { "id": 1, "name": "Admin User", "email": "admin@upf.ma", "role": "admin" }, "token": "1|abc123xyz..." }
GET /api/user AUTH REQUIRED

Get current authenticated user information

POST /api/logout AUTH REQUIRED

Logout and invalidate the current token

👨‍💼 Admin Endpoints

ADMIN ROLE REQUIRED
GET /api/admin/dashboard/stats AUTH ADMIN

Get dashboard statistics including student count, professor count, modules, etc.

Response:

{ "students": 156, "professors": 24, "filieres": 8, "modules": 48, "salles": 12 }
GET /api/admin/users?page=1 AUTH ADMIN

List all users with pagination

POST /api/admin/users/student AUTH ADMIN

Create a new student account

Request Body:

{ "name": "John Doe", "email": "john@student.upf.ma", "password": "password123" }
GET /api/admin/academic/filieres AUTH ADMIN

List all academic programs (filières)

GET /api/admin/timetable?view=all&professor_id=1 AUTH ADMIN

View timetables with optional filters (view, professor_id, filiere_id, groupe_id, module_id)

GET /api/admin/requests?page=1 AUTH ADMIN

List administrative document requests

PATCH /api/admin/requests/{id} AUTH ADMIN

Update request status (validate or reject)

Request Body:

{ "statut": "validated", "motif_rejet": null }

👨‍🏫 Professor Endpoints

PROFESSOR ROLE REQUIRED
GET /api/professor/dashboard/stats AUTH PROFESSOR

Get professor dashboard statistics

Response:

{ "modules_count": 5, "pending_notes": 12 }
GET /api/professor/modules AUTH PROFESSOR

List all modules assigned to the professor

GET /api/professor/grades/{moduleId} AUTH PROFESSOR

Get students and existing grades for a specific module

POST /api/professor/grades/{moduleId} AUTH PROFESSOR

Save or update grades for students in a module

Request Body:

{ "grades": { "1": { "cc1": 15.5, "cc2": 16.0, "final": 15.75 } } }
GET /api/professor/session-log?page=1 AUTH PROFESSOR

View session logs (cahier de textes)

📝 Example Usage

1. Login to get token:

# Using cURL curl -X POST http://localhost:8000/api/login \ -H "Content-Type: application/json" \ -d '{"email":"admin@upf.ma","password":"password"}'

2. Use token for API calls:

# Include token in Authorization header curl http://localhost:8000/api/admin/dashboard/stats \ -H "Authorization: Bearer YOUR_TOKEN_HERE"

3. Using JavaScript (Fetch API):

// Login const response = await fetch('/api/login', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ email: 'admin@upf.ma', password: 'password' }) }); const data = await response.json(); localStorage.setItem('token', data.token); // Make authenticated request const stats = await fetch('/api/admin/dashboard/stats', { headers: { 'Authorization': `Bearer ${data.token}` } });
